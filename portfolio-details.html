Kisan Procurement Centre

2026 Web Development Academic Project

This project was developed as a student-focused web application to understand real-world web development concepts such as authentication, role-based access, and content management.

Project Overview

The Kisan Procurement Centre allows users to log in as students or administrators. It provides features such as notes sharing, profile management, and a structured dashboard designed for academic use.

Key Highlights

  • Responsive layout for desktop and mobile
  • Student and admin role-based access
  • Notes upload and viewing system
  • Clean and user-friendly interface
  • Academic project-oriented design

Technical Implementation

The project was implemented using core web technologies. HTML was used for structure, CSS for styling and layout, and JavaScript for interactivity and logic handling. The focus was on learning best practices and building a functional student-oriented application.

This project helped me strengthen my understanding of frontend development and how real applications are structured and managed.
